# دليل قاعدة بيانات موقع الأنمي

## الملفات

- `anime_website.sql`: مخطط تثبيت جديد متكامل لقاعدة `anime_website`، يتضمن الجداول والعلاقات والفهارس والقيود والمشغلات.
- `migrate_existing.sql`: ترحيل لمرة واحدة لقواعد البيانات المنشأة بالمخطط السابق. **خذ نسخة احتياطية أولاً** وشغّله مرة واحدة فقط.
- `create_admin.php`: أداة CLI لإنشاء أول مدير باستخدام `password_hash()`، ولا تعمل من المتصفح.

## تثبيت جديد عبر phpMyAdmin

1. افتح phpMyAdmin.
2. اختر تبويب Import واستورد `anime_website.sql`.
3. تأكد أن إعدادات `config/database.php` تطابق الخادم واسم القاعدة.
4. من مجلد المشروع نفّذ في الطرفية:
   `php database/create_admin.php`
5. أدخل اسم المدير والبريد وكلمة مرور لا تقل عن 12 حرفاً.
6. احذف أداة `create_admin.php` من نسخة الإنتاج بعد إنشاء المدير، أو أبقها خارج مجلد الويب.

## قاعدة موجودة تحتوي على بيانات

1. صدّر نسخة احتياطية من قاعدة `anime_website`.
2. اختبر النسخة على قاعدة تجريبية أولاً.
3. استورد `migrate_existing.sql` بعد اختيار قاعدة البيانات المستهدفة.
4. لا تستورد `anime_website.sql` فوق قاعدة موجودة بهدف الترقية؛ فهو مخطط تثبيت جديد وليس أداة ترحيل عامة.

## الجداول

`users`, `anime`, `genres`, `anime_genres`, `episodes`, `comments`, `ratings`, `watchlist`.

## ملاحظات توافق

- يوصى بـ MySQL 8.0.16 أو أحدث لضمان تطبيق قيود `CHECK`.
- قاعدة البيانات تستخدم `utf8mb4` للنصوص العربية.
- لا يوجد مدير افتراضي بكلمة مرور ثابتة داخل ملف SQL.
- يتم تحديث متوسط تقييم الأنمي وعدد حلقاته عبر إجراءات ومشغلات SQL.
- مخطط التثبيت الجديد يجعل تعليقات الزوار ممكنة عبر `guest_name`، ويضيف حالات مراجعة التعليقات.
