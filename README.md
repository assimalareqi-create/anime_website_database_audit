# تقرير مشروع موقع الأنمي

## نظرة عامة

تم تطوير موقع متكامل لعرض الأنمي باستخدام PHP وBootstrap، يتيح للمستخدمين تصفح ومشاهدة الأنمي مع العديد من الميزات التفاعلية. كما يوفر الموقع لوحة تحكم للمسؤولين لإدارة جميع محتويات الموقع بطريقة آمنة وسهلة.

## الميزات الرئيسية

### واجهة المستخدم العامة
1. **الصفحة الرئيسية**: تعرض أحدث الأنمي، الأكثر مشاهدة، والأعلى تقييماً، وأحدث الحلقات
2. **صفحة تفاصيل الأنمي**: تعرض معلومات الأنمي، الحلقات، التقييمات، التعليقات، والأنمي المشابه
3. **صفحة مشاهدة الحلقات**: مشغل فيديو متكامل مع إمكانية التنقل بين الحلقات
4. **البحث المتقدم**: البحث حسب الاسم، التصنيف، الحالة، وسنة الإصدار
5. **نظام التقييمات**: يمكن للمستخدمين تقييم الأنمي من 1 إلى 5 نجوم
6. **نظام التعليقات**: يمكن للمستخدمين والزوار إضافة تعليقات على الأنمي والحلقات
7. **قائمة المتابعة**: يمكن للمستخدمين إضافة الأنمي إلى قائمة المتابعة الخاصة بهم

### لوحة تحكم المسؤول
1. **إدارة الأنمي**: إضافة، تعديل، حذف الأنمي مع رفع الصور
2. **إدارة الحلقات**: إضافة، تعديل، حذف الحلقات مع رفع الفيديوهات والصور المصغرة
3. **إدارة التصنيفات**: إضافة، تعديل، حذف التصنيفات
4. **إدارة المستخدمين**: إضافة، تعديل، حذف المستخدمين وتغيير صلاحياتهم
5. **إدارة التعليقات**: الموافقة، الرفض، حذف التعليقات

## التقنيات المستخدمة

- **لغة البرمجة**: PHP
- **قاعدة البيانات**: MySQL مع PDO للاتصال الآمن
- **واجهة المستخدم**: Bootstrap 5 RTL
- **مكتبات إضافية**: 
  - Font Awesome للأيقونات
  - Video.js لمشغل الفيديو
  - Swiper للعروض المتحركة

## ميزات الأمان

1. **التحقق من صحة المدخلات**: تنظيف وفلترة جميع المدخلات لمنع هجمات XSS
2. **استعلامات مجهزة مسبقاً**: استخدام PDO مع الاستعلامات المجهزة للوقاية من حقن SQL
3. **التحقق من الصلاحيات**: التحقق من صلاحيات المستخدم قبل كل عملية حساسة
4. **تشفير كلمات المرور**: استخدام دالة `password_hash` لتشفير كلمات المرور
5. **جلسات آمنة**: إدارة الجلسات بطريقة آمنة مع تحديد مدة صلاحية

## تعليمات التثبيت

1. **متطلبات النظام**:
   - PHP 7.4 أو أحدث
   - MySQL 5.7 أو أحدث
   - خادم ويب (Apache أو Nginx)

2. **خطوات التثبيت**:
   - استخراج الملفات إلى مجلد الخادم
   - إنشاء قاعدة بيانات جديدة
   - استيراد ملف `database/anime_website.sql` إلى قاعدة البيانات
   - تعديل ملف `config/database.php` بمعلومات الاتصال بقاعدة البيانات
   - تعديل ملف `config/config.php` بإعدادات الموقع
   - التأكد من صلاحيات الكتابة لمجلدات الرفع في `assets/uploads`

3. **بيانات الدخول الافتراضية**:
   - المسؤول: admin / password
   - مستخدم عادي: user / password

## الاستخدام

### المستخدم العادي
1. تصفح الأنمي والحلقات من الصفحة الرئيسية
2. استخدام البحث المتقدم للعثور على أنمي محدد
3. إنشاء حساب أو تسجيل الدخول للوصول إلى الميزات التفاعلية
4. مشاهدة الحلقات وإضافة تعليقات وتقييمات
5. إدارة قائمة المتابعة الشخصية

### المسؤول
1. تسجيل الدخول إلى لوحة التحكم من خلال `/admin`
2. إدارة الأنمي والحلقات والتصنيفات
3. إدارة المستخدمين وتعديل صلاحياتهم
4. مراجعة والموافقة على التعليقات

## التخصيص

- تعديل ملف `assets/css/style.css` لتغيير مظهر الموقع
- تعديل القوالب في مجلد `templates` لتغيير هيكل الصفحات
- تعديل الإعدادات العامة في ملف `config/config.php`
